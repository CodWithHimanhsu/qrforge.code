    Help and questions
    

    
    Is this a static or a dynamic QR code?
      
    Static. The code contains your actual content (a URL, text, Wi-Fi details and so on). It works without QRForge, never expires, and has no scan limit. The trade-off is that it cannot be edited: you cannot change the destination after printing. Services that offer editable or trackable codes use a dynamic code, which points to a redirect address on their server. That needs a server that stays online, which is why those services charge subscriptions. QRForge does not offer dynamic codes.

    Is my content stored?
      
    QRForge does not save or log what you enter. The server receives it only to build your image and send it back. As with any website, the hosting provider's infrastructure may keep ordinary connection records. For Wi-Fi passwords or other sensitive data, the local version (which never leaves your computer) is the more private choice.
    
    
    
    {% endif %}
    
    Can a QR code expire?
      
    A static code has no expiry date from QRForge. It stops being useful only if the encoded destination stops working or the information inside becomes out of date.
    
    
    
    
    Why does a code scan but the page does not load?
      
    The code may contain the right address while the website is down, blocked, misspelled, or unreachable without internet.
    
    
    
    
    Why does my QR code look dense?
      
    More content needs more modules. A shorter URL usually produces a simpler code that is easier to scan at small sizes.
    
    
    
    
    Why does my QR code fail to scan?
      
    Common causes: too small, low contrast, a missing blank margin, blurry or glossy printing, glare, damage, inverted colors, or a destination that is not available. Test the actual printed or on-screen result.
    
    
    
    
    Is there a limit on how many codes I can make?
      
    No. There are no quotas, watermarks or accounts. Each individual code has a size limit set by the QR standard (about 2,900 bytes at the lowest error-correction level).
